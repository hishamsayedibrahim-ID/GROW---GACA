# فخ النصيحة · The Advice Trap

An Arabic GROW coaching simulation for GACA leadership programmes. Leaders coach "Sarah", a strong performer whose results have slipped, through Goal, Reality, Options and Will, and see how advice, assumptions, questions and listening change what she shares.

**Live site:** enable GitHub Pages (Settings > Pages > Deploy from branch > `main` / root). The link will be `https://<owner>.github.io/<repository>/`.

## What is in this repository

| File | Purpose |
|---|---|
| `index.html` | The whole simulation. Self-contained: brand fonts and logo are embedded, no server, login or API keys. |
| `.nojekyll` | Tells GitHub Pages to serve the file as is. |

## Running it

- **Offline:** download `index.html` and double-click it.
- **Online:** GitHub Pages as above, or drag the file onto Netlify Drop.

## In the session

- 12 decisions across the four GROW stages, with two optional returns to an earlier stage.
- Short feedback after each decision; Sarah's trust in the leader shown as a simple indicator.
- End screen: what was really going on, two possible futures, a four-part formative rubric, a review of each decision with a better option, replay from any stage, and a short reflection.
- Facilitator mode (link in the footer) shows response types, Sarah's hidden state and a discussion prompt for each decision.

## Data and privacy

Progress and reflections are stored only in the participant's own browser. Nothing is sent anywhere. On shared laptops, press "ابدأ من جديد" at the end.

## Notes

- The rubric is a formative learning aid. It is not validated and must not be used to assess individuals.
- Branding follows the GACA Design System v2.0 (Co Headline and Co Text, navy, mint and GACA Blue). The fonts are subset and embedded; confirm that GACA's font licence covers web use before making this repository public.
- All dialogue is in the `NODES` object inside `index.html`.
